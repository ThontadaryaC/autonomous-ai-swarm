# ⚡ Autonomous Multi-Agent AI Software Engineering Swarm

An autonomous multi-agent software engineering team powered by local/cloud LLMs with continuous web scraping, real-time news intelligence, 3D graphics & health application mastery, and microsecond indexed database memory.

---

## 👥 The 3-Agent Collaborative Swarm

| Agent | Model | Primary Role |
| :--- | :--- | :--- |
| **Agent 1: Backend & Security** | `qwen3:4b` | Architecture, APIs, Cybersecurity audits (OWASP / SQLi / XSS prevention), and folder management. |
| **Agent 2: Frontend Engineer** | `gemma3:4b-it` | 3D WebGL / Three.js canvas, responsive glassmorphism CSS, and interactive JavaScript. |
| **Agent 3: QA & Test Automation** | `llama3.2:latest` | Automated test suite execution, security validation, and iterative feedback loops. |

---

## 🌟 Key Features

1. **🚀 Visual Web GUI Cockpit (`dashboard.py`)**:
   - Access at `http://localhost:8080` (or 24/7 on Render).
   - Launch prompts, inspect agent chains-of-thought, and explore generated project files.

2. **🏥 5-Day 3D Health App & Security Mastery (`health_3d_curriculum.py`)**:
   - Programmed curriculum for Three.js 3D body/organ visualizers, vitals telemetry, AES-256 encrypted records vault, and HIPAA compliance.

3. **🕷️ Autonomous Web Scraping & Self-Improvement (`autonomous_web_agent.py`)**:
   - Automatically detects internet connectivity to scrape tutorials, auth patterns, and anti-bot mitigation techniques into runnable Python playbooks.

4. **⚡ Microsecond Database Indexing (`autonomous_db_indexer.py`)**:
   - SQLite FTS5 Full-Text Indexing with sub-2 millisecond memory recall (< 2 ms).

5. **🌍 Live Daily Intelligence & News (`daily_intelligence.py`)**:
   - Real-time updates for USA News, India News, and today's learned skills.

## 🚀 Quick Start (Local)

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Launch the Web Cockpit GUI
python dashboard.py

# 3. Or run a swarm task directly
python multi_agent_team.py "create a new folder in desktop and build a modern web app"
```
